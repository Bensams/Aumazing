## Description

```
Aumazing is a gamified 2D mobile learning app for children with Autism Spectrum
Disorder, built to support early intervention and home-based therapy in Davao
City. The child plays a short gamified pre-assessment; an AI model reads how
they play — accuracy, response time, retries — and recommends which learning
modules to do next. A post-assessment then shows the parent what actually
changed. The games library works fully offline.

An Information Technology capstone project presented to the Faculty of
Information Technology, Assumption College of Davao.
```
